## 3. 📚 รายละเอียดบทเรียนช่วงเช้า (Morning Sessions)

### Session 1: Project Management & Proposals & AI Codex

#### 1. การเขียน Proposal (15 นาที)
ตัวอย่างกรณีศึกษา: **ระบบจัดการข้อมูลบุคลากรในองค์กร (Personnel Information Management System)**
* **Problem Statement:** ข้อมูลกระจัดกระจาย ค้นหาช้า (ใช้กระดาษและ Excel) ค้นหาใช้เวลา 20-30 นาที/ครั้ง เสี่ยงต่อความผิดพลาด
* **Objective & Scope:** พัฒนาเว็บแอปพลิเคชันรวมศูนย์สำหรับบันทึก ค้นหา แก้ไขข้อมูลประวัติ ตำแหน่ง แผนก การลา (ไม่รวมระบบ Payroll ในเฟสแรก)
* **Approach & Timeline (8 สัปดาห์):**
  1. สัปดาห์ 1-2: ออกแบบฐานข้อมูล
  2. สัปดาห์ 3-6: พัฒนาระบบ Backend/Frontend
  3. สัปดาห์ 7: ทดสอบระบบ (QA)
  4. สัปดาห์ 8: อบรมผู้ใช้งาน
* **Resource & Budget:** ทีมพัฒนา 3 คน (Developer 2, QA 1) | งบประมาณ 150,000 บาท
* **Expected Outcome:** ลดเวลาค้นหาข้อมูลลง >70% และลดความซ้ำซ้อนของข้อมูล

#### 2. AI for Information Work: OpenAI Codex CLI (60 นาที)
* **Codex คืออะไร:** AI Agent จาก OpenAI ที่ทำงานผ่าน Command Line (CLI) อ่านคำสั่งภาษาธรรมชาติและลงมือปฏิบัติตามคำสั่งกับไฟล์จริง
* **ขั้นตอนการติดตั้ง:**
  1. ติดตั้ง Node.js LTS จาก `nodejs.org`
  2. เปิด Terminal / CMD พิมพ์: `npm install -g @openai/codex`
  3. ตรวจสอบเวอร์ชัน: `codex --version`
  4. พิมพ์ `codex` เพื่อเริ่มต้นและทำการ Sign-in ผ่านเบราว์เซอร์
* **ตัวอย่างการสั่งงาน:**
  * `Codex> สรุปเนื้อหาไฟล์ report.txt ให้หน่อย`
  * `Codex> สร้างไฟล์ summary.csv จากข้อมูลใน data.xlsx`
  * `Codex> เขียนสคริปต์เช็คไฟล์ซ้ำในโฟลเดอร์นี้ให้หน่อย`

### Session 2: Programming for Fun (Node.js)

แนะนำการติดตั้ง IDE และเครื่องมือทดสอบ API:

### กติกาการกู้ยืมเงินธนาคาร (Bank Rules)

* **วงเงินกู้ยืม:** กู้ได้ครั้งละไม่เกิน **5,000 บาท**
* **ระยะเวลาดำเนินการอนุมัติ (Processing Time):** ใช้เวลา **20 นาที** หลังจากยื่นกู้ ธนาคารจึงจะโอนเงินให้กลุ่ม
* **ระยะเวลาเรียกคืนเงิน (Repayment Window):** ต้องชำระคืนภายใน **25 นาที** หลังจากได้รับเงิน
* **อัตราดอกเบี้ย:** **2.5%** ต่อการยืม 1 ครั้ง
* **ตัวอย่างการคำนวณ:**
  $$	ext{ยอดเงินกู้} = 5,000 	ext{ บาท} \quad \implies \quad 	ext{ดอกเบี้ย (2.5\%)} = 125 	ext{ บาท}$$
  $$	ext{ยอดเงินที่ต้องชำระคืนรวม} = 5,000 + 125 = 5,125 	ext{ บาท}$$

## 5. 💻 ระบบ Broadcast Board Management Dashboard

เพื่อความสมจริงในการดำเนินกิจกรรม ได้มีการพัฒนา **Broadcast Board Web Application** (`index.html`) ทำหน้าที่เป็นจอแสดงผลหลักกลางห้องประชุม (Central Dashboard) สำหรับสุ่มวิกฤต ประกาศข่าวสารตลาดแรงงาน และประมวลผลอันดับการแข่งขัน

### ฟีเจอร์หลักของระบบ (Key Features)

1. **Countdown Ring & Cycle Control:**
   * วงแหวนนับถอยหลังรอบเหตุการณ์ (ตั้งค่าได้: 45 นาที, 30 นาที, 15 นาที, 5 นาที, 1 นาที)
   * เมื่อหมดเวลา ระบบจะส่งเสียงไซเรนแจ้งเตือนและสุ่มสไลด์วิกฤตขึ้นหน้าจออัตโนมัติ
2. **Crisis & Talent Market Event Generator:**
   * ระบบสุ่มการ์ดเหตุการณ์แบบปรับได้ 3 ระดับความรุนแรง (**Light, Medium, Heavy**)
   * แสดงการ์ดเปรียบเทียบผลกระทบ (Split View): **วิกฤตฝั่งส่งออก vs ขั้นตอนการแก้ไขฝั่งรับคน**
3. **Dividend Recovery Event Banner:**
   * ป้ายประกาศจ่ายเงินปันผลฉุกเฉิน (Pop-up Banner) พร้อมนาฬิกานับถอยหลังระยะเวลาการรับเงิน
   * ระบบเสียงกระดิ่งปันผลสดใสรื่นเริง (Chime Sound via Web Audio API)
4. **Ranking & Leaderboard with Podium:**

## 6. 🛠️ คู่มือการติดตั้งและการใช้งานโปรแกรม (Setup & Usage Guide)

### การเปิดใช้งาน Broadcast Board
1. ดาวน์โหลดไฟล์ `index.html`
2. เปิดไฟล์ผ่าน Web Browser (Google Chrome, Microsoft Edge, Firefox, Safari)
3. ไม่จำเป็นต้องติดตั้ง Server รองรับการทำงานแบบ Offline หรือเชื่อมต่อหน้าจอ Projector กลางห้อง

### การตั้งค่าและสุ่มเหตุการณ์ (Settings Drawer)
1. คลิกไอคอน **⚙ (ตั้งค่า)** มุมขวาบน
2. เลือกความยาวรอบเวลา (เช่น 15 นาที หรือ 1 นาทีสำหรับการทดสอบ)
3. กำหนดรอบเวลาและการจ่ายเงินปันผลอัตโนมัติ (Automated Dividend)
4. เลือกระดับความรุนแรงของวิกฤต (**Light, Medium, Heavy**)
5. กรณีบริษัทล้มละลาย สามารถพิมพ์ชื่อทีมในช่อง **"ประกาศบริษัทล้มละลาย"** แล้วกดปุ่มเพื่อแจ้งเตือนทั้งห้องประชุม

### การจัดการทีมและการ Export ผลการเรียน (Ranking & Excel Export)
1. ไปที่แท็บ **"🏆 Ranking ทีม"**
2. เพิ่มรายชื่อทีมและระบุยอดเงินคงเหลือเริ่มต้น
3. เมื่อจบเกม คลิก **"📎 เลือกไฟล์ Excel (.xlsx)"** เพื่ออัปโหลดไฟล์รายชื่อนักศึกษา
4. ระบบจะแมปชื่อทีมในไฟล์ Excel กับอันดับเงินคงเหลือในระบบ พร้อมคำนวณเกรด (A, B+, B) ให้อัตโนมัติ
5. คลิกปุ่ม **"💾 Export ผลลัพธ์ (.xlsx)"** เพื่อดาวน์โหลดไฟล์รายงานสรุปเกรดนำส่งสถาบัน
